# Codex on Windows

Complete the [installation and grants](README.md) in PowerShell first. Keep the absolute path variables from that session. These commands register the read/history identity B. Check the name is unused before adding it.

```powershell
codex mcp list
codex mcp add trace-practice -- "$python" -I "$server" --binding "$agentB"
codex mcp get trace-practice
```

Open a fresh Codex session, inspect its MCP tools and ask for the current fictional project budget. Grant access only to fictional labels you intend Codex to receive. To disconnect, run `codex mcp remove trace-practice` and close active sessions.

The Step 45 check used a disposable Codex home, the installed Codex CLI and its app-server. It registered the server, discovered eight tools and called `memory_status` from an ephemeral thread. This exercised the host integration without a model turn. [Official Codex MCP guide](https://developers.openai.com/codex/mcp/)
