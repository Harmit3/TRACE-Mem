# Offline demonstration guide

From the repository root, run `python -m trace_mem.demo` and open http://127.0.0.1:8765. Use `--port 8766` if that port is occupied. Stop with Ctrl+C. The server binds to loopback and serves a fixed file and API allowlist. Use the numeric address shown in its startup output.

1. Select B3, cap one, replay through day three. The initial office is superseded by the verified correction. The visible fact shows its source reference and validity start.
2. Query day one with the same replay. The previous office remains retrievable with a closed validity interval.
3. Compare B2 or B3 at cap zero. The implicit correction lacks enough confirmation to supersede the prior office.
4. Move the replay through day four. The speculative move is deferred. Try cap two to see the second scripted verdict.
5. Compare the private note on day two before and after replaying day five. After deletion, querying the earlier date still excludes it.
6. In Archived results, compare the 50% closed-loop and fixed-stream conditions. The performance ranking reverses. The horizon and paired-interval plots come from the frozen research artifacts.

The console requires no credentials, models, or internet access. Scenario claims and verifier verdicts are fictional. The dashboard displays saved experiments, including negative results, and makes no fresh inference. This is technical project documentation for the standalone research release.
