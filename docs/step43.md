## Installation, operation and demonstration

For the offline presentation, extract the source ZIP, open a terminal in the directory containing README.md and use CPython 3.14. Run `python -m trace_mem.demo` and open the printed loopback address. No pip installation, model, account, internet connection, or payment is required for this path. If the port is occupied use `python -m trace_mem.demo --port 8766`. Stop with Ctrl+C. Changing the replay controls recomputes the fictional state from the beginning. Reload to restore the initial controls.

1. In **Replay lab**, keep B3 and a one-call cap. At day five the office is Maple Studio. Query day one to see Cedar Hall. Query day two after day five to verify the deleted routing note stays unavailable.
2. Switch to a zero cap and compare the final office. Replay day four at cap two to see the uncertain move deferred. Discuss what one extra verification can buy.
3. Use the **Archived results** navigation link. At 50% compare chronological and fixed replay. The paired difference changes sign. The two plots open at full size. If the browser or server is unavailable, open the local [paired-results figure](../research/figures/budget-reversal.pdf), [horizon figure](../research/figures/horizon-sensitivity.pdf) and [results table](../research/tables/results.md).
4. For a separate conversational rehearsal, extract the entire private Windows ZIP, double-click **TRACE-Mem Workspace.exe** and choose **Open practice profile**. Follow the fictional [practice guide](supervised_practice.md). Use only that window for sample data. Confirm a proposal, ask in a new chat, correct it with an effective date, inspect earlier evidence, forget the label and delete the practice chats separately. Use the long-history dashboard for Step 42. Its three probes answer a different question from the controller comparison.

The [desktop instructions](../desktop/START%20HERE.txt) cover prerequisites, recovery, upgrades, uninstall, local models and both storage modes. Start Ollama with an existing model for generation, then refresh the picker. Offline lookup still works when generation is unavailable. The optional pinned MiniLM worker uses a trusted installed interpreter and cached model. A missing encoder falls back to lexical retrieval. Restart the backend after repairing the encoder installation. Keep the launcher open while using the browser and close it to stop the server. Before a migration, retain any required backup privately. Restore only after reviewing its deletion history. Keep a damaged profile for diagnosis and select a separate recovery profile. For source-mode development, see [Workspace usage](workspace.md). Use the packaged profile when testing Windows protection.

## Changelog and known limitations

Research source 1.1.0 consolidates the previously frozen research and Workspace through Step 42, adds the audited manuscript, and adds a replayable numerical manuscript check. Desktop 0.42.1 opens practice before reading the personal profile selector. A malformed personal selector also exposes the recovery control. Desktop 0.42.0 introduced the optional local encoder, structured evidence sharing, guided practice and protected chat migration. Earlier releases and manifests retain their historical versions.

Windows testing used fresh extraction on the development computer. A clean Windows VM or Sandbox was unavailable. The unsigned package has no independent security or accessibility certification. DPAPI protects content at rest under the active Windows account. Same-user processes, visible old transcripts, backups, provider logs and SQLite metadata remain outside managed forgetting. Source-mode chat storage has different protection. Extraction can miss facts, semantic search can miss paraphrases, approved data can still be false, and generated answers may be incorrect. Authorization and tested prompt boundaries have limited empirical coverage.
