# Provisional abstract for independent research

Long-horizon memory agents must decide which conflicting writes to check when verification is expensive and early decisions change later memory state. We evaluate TRACE-Mem, a temporal memory system with learned and heuristic verification policies, across 100 authored histories in ten scenario families. At 250 verification calls, learned pacing improved exact temporal-state accuracy over heuristic pacing by 6.7 percentage points in chronological replay (paired family bootstrap 95% interval 0.7 to 12.3), but trailed by 11.3 points on a matched fixed stream. A post-hoc analysis of the same histories found that the learned policy did not consistently beat an early-call baseline and lost accuracy while underspending under an overestimated planning horizon. Higher memory accuracy did not produce better short-answer performance in the tested reader subset. An exploratory 14-question LongMemEval diagnostic completed only one history for managed-policy comparison because of extraction limits and failures. These results identify conditions under which learned verification helps synthetic temporal memory and limitations on its evaluation, with external and end-to-end superiority unresolved.
