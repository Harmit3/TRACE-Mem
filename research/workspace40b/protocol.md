Run each original message once through the shared hybrid extractor. Simulate a reviewer accepting asserted proposals, explicitly replacing only on correction, and declining uncertainty and duplicate or unresolved conflicts. No human annotation. No gold repair, tuning or retries.

Use exact normalized answer match, failure inclusive. Include a conditional denominator when the selected evidence contains the expected nonmissing value. Grade extraction by message-specific exact slot, value, intent triples. Report TP, FP, FN, F1, wrong saved proposals, uncertainty, abstentions, errors, stage token counts and elapsed time.
