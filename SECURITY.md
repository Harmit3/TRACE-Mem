# Security and privacy

Run Workspace on loopback for one local user. Use a fictional profile for demonstrations. The private Windows build uses current-user DPAPI for saved memory and transcript content. Same-user processes, backups, open browser tabs, provider logs and database metadata remain outside its protection. The source-mode database has different storage protection. Managed forgetting revokes stored versions and future context; delete visible transcripts separately. [Storage and recovery](docs/windows_beta_042.md)

When reporting a problem, record the version, affected boundary and minimum fictional example. Use GitHub's private vulnerability reporting option **if enabled**. Otherwise request a private contact channel from the maintainer without posting sensitive details. Never post real transcripts, credentials, local databases or restricted benchmark material. The project has no independent security certification or guaranteed response time.
